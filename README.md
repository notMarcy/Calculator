# Calculator2025

Данный репозиторий предназначен для разработки консольного приложения "Калькулятор" в рамках индивидуального итогового проекта по крусу "ОиМП". Своей основной целью ставлю продемонстрировать глубокое понимание принципов объектно-ориентированного программирования (ООП) и навыков разработки на языке программирования C++.
